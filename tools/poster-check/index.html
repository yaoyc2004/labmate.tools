    QUESTIONS · POSTER CHECK

    Frequently asked

    Is my poster file uploaded anywhere?

    No. The file is read on your computer and never uploaded, so it is safe for unpublished work.

    Which file types can it check?

    PDF, PowerPoint (PPTX), PNG and JPG.

    What does Poster Check look at?

    Whether your file's shape and size match the print size you will order and fit the board limit from the conference page, plus image resolution and text size at full print size. You get a checklist PDF and an email for the print shop.

    What doesn't it check?

    Colour mode and profile, bleed, transparency and overprint, and spelling. A browser can't judge these reliably, so they go on the checklist as questions for the print shop.
